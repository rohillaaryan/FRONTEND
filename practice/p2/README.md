# Searching Snake

A simple search-page practice project built with HTML, CSS, and JavaScript.

## Project Structure

* `index.html` — page structure, search input, buttons, and results container
* `styles.css` — layout and visual styling
* `script.js` — button interaction and search-related behavior

## Design Decisions

I chose a simple layout so the search bar and results area are easy to understand and use.

* CSS Grid is used for the results area so results can be arranged in multiple columns.
* Flexbox is used for the form controls to keep the search input and buttons aligned.
* Unique IDs are used for interactive elements so they can be easily accessed from JavaScript.
* A separate results container is used so search results and the empty-state message can be managed independently.
* The design uses a minimal layout with spacing between elements to keep the page readable.

## Current Features

* Search input field
* Search button
* Clear button
* Results container
* Empty-state message when there are no results
* Responsive grid layout for results

## Purpose

This project was created as frontend practice to improve my understanding of HTML structure, CSS Grid/Flexbox, DOM manipulation, and JavaScript event handling.
